# B24CS53 Computer Graphics with OpenGL

A web based, interactive slide deck for the **B24CS53 Computer Graphics** course,
covering all five modules of the syllabus based on the prescribed textbook
*Computer Graphics with OpenGL* by Hearn, Baker and Carithers (4th ed., Pearson).

**Lecturer:** Mr. Bharath

## Contents

- `index.html` : home page with course info, module cards, downloads and sources.
- `modules/module1.html` to `module5.html` : the five module slide decks.
- `css/style.css` : shared theme and presentation styles.
- `js/deck.js` : slide navigation engine (keyboard, touch, overview, print).
- `js/visuals.js` : interactive demos using anime.js and three.js.
- `js/spotlight.js` : click a section to enlarge it over a blurred background.
- `images/` : reference images from Wikimedia Commons (CC BY-SA), with attribution.

## Modules

1. Computer Graphics Hardware and Software (Textbook Ch 1, 2)
2. Graphics Output Primitives and Attributes (Ch 3, 4)
3. Algorithms and 2D/3D Transformations (Ch 5, 6, 8)
4. Interactive Input Methods and Graphical User Interfaces (Ch 18)
5. Computer Animation (Ch 11)

## Controls

Arrow keys or Space to navigate, `O` for overview, `F` for fullscreen,
`P` to print or save as PDF, `H` for keyboard help. Click any section to
spotlight it in the centre of the screen.

## Sources

- Hearn, Baker and Carithers, *Computer Graphics with OpenGL*, 4th ed., Pearson, 2014.
- Edward Angel, *Interactive Computer Graphics*, 5th ed., Pearson, 2008.
- Khronos OpenGL Registry and OpenGL / GLU / GLUT reference pages.
- Reference images: Wikimedia Commons, licensed CC BY-SA 3.0 (attribution on each slide).

Interactive demos load anime.js and three.js from a CDN, so those animations
need an internet connection; all other content works offline.
