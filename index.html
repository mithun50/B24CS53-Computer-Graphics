Course Outcomes

What you will be able to do

  • CO1 · Explain the working of graphics hardware & software.
  • CO2 · Apply OpenGL to fundamental graphics operations.
  • CO3 · Apply 2D/3D geometric transformations using matrices.
  • CO4 · Build interactive graphics systems with GUIs & menus.
  • CO5 · Construct animations using OpenGL procedures.

Prerequisites

  • Coordinate Geometry
  • Matrices and Vectors
  • Linear Transformations
  • Basic Trigonometry
